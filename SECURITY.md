# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting form from the repository's
Security tab and include a clear description, affected versions, reproduction
steps, proof of concept where safe to provide, and impact.

The maintainer will acknowledge the report, assess impact, and coordinate a
fix before public disclosure.

## Supported Versions

Security fixes are made against the current released version and the main
branch. Older releases may receive a fix when the issue is practical to
backport.
